# Neural Network from Scratch

This project demonstrates the implementation of a simple neural network from scratch using only NumPy. The network is trained to classify points in a 2D space generated by the spiral dataset, a popular dataset for testing classification algorithms.

## Features

- **Custom Neural Network Layers**: Implementation of dense layers with forward and backward propagation.
- **Activation Functions**: Includes ReLU and Softmax activation functions with their respective backpropagation.
- **Loss Functions**: Implements Categorical Crossentropy loss and a combined Softmax activation with Categorical Crossentropy loss function for efficiency.
- **Optimizers**: Includes implementations of common optimization algorithms such as SGD (with momentum), Adagrad, RMSprop, and Adam.
- **Training Loop**: The network is trained for a specified number of epochs with real-time accuracy, loss, and learning rate logging.

## Installation


## Usage

To run the neural network training:

1. **Generate the Dataset**: The spiral dataset is generated using `nnfs.datasets.spiral_data`.
2. **Define the Model**: The model consists of two dense layers with ReLU and Softmax activations.
3. **Train the Model**: The model is trained using the Adam optimizer for 10,000 epochs. Training progress is printed every 100 epochs.

```python
python nn_from_scratch.py
```

## Project Structure

- **nn_from_scratch.py**: The main script containing the entire neural network implementation.
- **README.md**: This file, providing an overview of the project.

## Neural Network Components

- **Layer_Dense**: Implements a fully connected layer with forward and backward propagation.
- **Activation_ReLU**: Implements the ReLU activation function and its derivative for backpropagation.
- **Activation_Softmax**: Implements the Softmax activation function and its derivative.
- **Optimizer_SGD**: Stochastic Gradient Descent optimizer with optional momentum.
- **Optimizer_Adagrad**: Adagrad optimizer for adaptive learning rates.
- **Optimizer_RMSprop**: RMSprop optimizer, which maintains a moving average of squared gradients.
- **Optimizer_Adam**: Adam optimizer, combining the benefits of both RMSprop and momentum.
- **Loss_CategoricalCrossentropy**: Computes the categorical crossentropy loss.
- **Activation_Softmax_Loss_CategoricalCrossentropy**: Combined Softmax activation and Categorical Crossentropy loss for more efficient backpropagation.

## Customization

- **Hyperparameters**: Adjust the learning rate, decay, and other hyperparameters in the optimizer definitions.
- **Network Architecture**: Modify the number of layers, neurons, or activation functions as needed.
- **Epochs**: Change the number of training epochs to improve or shorten the training process.
